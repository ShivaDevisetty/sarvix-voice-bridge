# Example: design review by phone

Task: ask which of two non-sensitive calendar layout variations the owner prefers.

1. Show the user screenshots and a concise comparison in the normal chat first.
2. Ask for explicit permission for a single phone call, including cost and number.
3. Use `demo` first to ensure local configuration is correct.
4. If explicitly approved, use the live call with the permitted E.164 destination.
5. Poll the single call ID; do not auto-redial.
6. Present the transcript and ask the user to confirm their decision in chat.
7. Proceed only under standard repository rules and normal action permissions.
